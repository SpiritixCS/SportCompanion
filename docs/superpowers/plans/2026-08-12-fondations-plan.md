# Fondations Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Scaffold the Next.js app, implement the design system as real code (tokens + base components), stand up the SQLite/migrations skeleton, run the one-shot data pipeline, and prove the VM deploy pipeline works end-to-end — with zero product screens and zero business logic.

**Architecture:** Next.js 16 App Router, TypeScript strict, Tailwind v4 with a CSS-first `@theme` token block, hand-built base components (no UI/icon library), `better-sqlite3` behind a small hand-rolled migration runner, Vitest + Testing Library for tests. Everything co-located: each component/module ships next to its test.

**Tech Stack:** Next.js 16, React 19, TypeScript 5, Tailwind CSS v4, better-sqlite3, Vitest, @testing-library/react, jsdom.

## Global Constraints

- TypeScript strict mode everywhere (`tsconfig.json` → `"strict": true`).
- `next.config.ts` must set `output: "standalone"` — required by `deploy/sportcompanion.service` (see `DEPLOYMENT.md`).
- No generic UI or icon library (no shadcn, no Lucide, etc.) — every visual primitive is hand-built to match the Claude Design prototype exactly (`CLAUDE.md` §0 priority #1: fidelity to design is an objective, not inspiration).
- Every visual component that supports theming takes a prop `accent: "cobalt" | "sage" | "brass"` — never a hardcoded color.
- No speculative database tables in this phase — only the migration runner + `_migrations` bootstrap table.
- Package manager: npm (matches the VM and the decommissioned v1, see `DEPLOYMENT.md`/`CLAUDE.md` §2).
- Node target: 20.x (VM runs 20.20.2 — see `DEPLOYMENT.md`).
- Design tokens — copy verbatim, do not re-derive:
  - Colors: `--paper #FFFFFF`, `--canvas #F6F7F4`, `--ink #111310`, `--graphite #6E736B`, `--hairline #E5E7E1`, `--cobalt #1F3BE0`, `--sage #2E7D63`, `--brass #A9782C`, `--alert #B3402E`
  - Radii: card `20px`, field `14px`, pill `999px`
  - Type scale (px): `11, 13, 15, 18, 24, 32, 44`, plus `96` for the rest timer / rep counter (out-of-scale, per `CLAUDE.md` §4)
  - Fonts: Archivo (variable, titles/numbers/timers), Inter Tight (body/labels/buttons)

```tsx
"use client";

import { useEffect } from "react";
import { IconClose } from "./icons/IconClose";

export function Sheet({
  open,
  onClose,
  title,
  children,
}: {
  open: boolean;
  onClose: () => void;
  title: string;
  children: React.ReactNode;
}) {
  useEffect(() => {
    if (!open) return;
    function handleKeyDown(e: KeyboardEvent) {
      if (e.key === "Escape") onClose();
    }
    document.addEventListener("keydown", handleKeyDown);
    return () => document.removeEventListener("keydown", handleKeyDown);
  }, [open, onClose]);

  if (!open) return null;

  return (
    <div className="fixed inset-0 z-50 flex items-end">
      <div
        data-testid="sheet-backdrop"
        className="absolute inset-0 bg-ink/40"
        onClick={onClose}
      />
      <div className="relative w-full bg-paper rounded-t-card p-5">
        <div className="flex items-center justify-between mb-4">
          <span className="font-archivo text-18 font-semibold">{title}</span>
          <button type="button" onClick={onClose} aria-label="Fermer">
            <IconClose />
          </button>
        </div>
        {children}
      </div>
    </div>
  );
}
```

```typescript
import type Database from "better-sqlite3";
import { readdirSync, readFileSync } from "node:fs";
import path from "node:path";

export function runMigrations(
  db: Database.Database,
  migrationsDir: string,
): { applied: string[] } {
  db.exec(
    "CREATE TABLE IF NOT EXISTS _migrations (filename TEXT PRIMARY KEY, applied_at TEXT NOT NULL)",
  );

  const alreadyApplied = new Set(
    (db.prepare("SELECT filename FROM _migrations").all() as { filename: string }[]).map(
      (row) => row.filename,
    ),
  );

  const files = readdirSync(migrationsDir)
    .filter((f) => f.endsWith(".sql"))
    .sort();

  const applied: string[] = [];

  for (const filename of files) {
    if (alreadyApplied.has(filename)) continue;

    const sql = readFileSync(path.join(migrationsDir, filename), "utf-8");
    const transaction = db.transaction(() => {
      db.exec(sql);
      db.prepare("INSERT INTO _migrations (filename, applied_at) VALUES (?, ?)").run(
        filename,
        new Date().toISOString(),
      );
    });

    try {
      transaction();
    } catch (err) {
      throw new Error(
        `Migration ${filename} failed: ${err instanceof Error ? err.message : String(err)}`,
      );
    }

    applied.push(filename);
  }

  return { applied };
}
```
